# Signo de Nós

Perguntas para conversar a partir de uma leitura simbólica de signos. Astrologia aqui é reflexão e entretenimento, sem diagnóstico, previsão ou veredito sobre uma relação.

## “A gente conversa depois.” Depois quando?

Cena fictícia da amostra do Manual de Nós: um convite de família foi aceito sem consultar. Na cozinha, uma pessoa pergunta por quê. A outra diz “não quero discutir agora” e sai. A frase deixou uma dúvida: o assunto ficou para depois ou foi encerrado?

Uma pergunta possível, se houver vontade e liberdade para conversar:

> Você quer retomar a conversa sobre o convite? Quando seria possível?

“Não quero” e “ainda não sei” também são respostas. Combinar um horário não resolve sozinho o convite aceito sem consulta. Se houver medo, coerção ou risco, esta proposta não serve para negociar sua saída.

[Ler a amostra gratuita — uma cena, duas versões e um pedido para adaptar](https://signodenos.com.br/manual-de-nos/amostra/?utm_source=github&utm_medium=owned&utm_campaign=amostra_pausa)

A amostra abre sem cadastro e pode ser impressa ou salva como PDF pelo navegador. Você pode ler sozinho, usar só uma frase ou deixar a proposta de lado. Não é terapia nem relatório personalizado; não há produto pago disponível.

## Quer começar pelos signos?

[Escolha dois signos e encontre uma pergunta](https://signodenos.com.br/compatibilidade/?utm_source=github&utm_medium=owned&utm_campaign=entrada_signos). A ferramenta usa signos solares, sem pedir nome, data, hora ou local de nascimento. Você pode discordar da leitura; ela não sabe o que a outra pessoa sente.

## Como contribuir

[Envie um relato sobre o funcionamento do site](https://github.com/lucaskawazoi/signodenos/issues/new?template=feedback.yml): indique a página, o que tentou fazer e o que aconteceu. Os relatos são públicos, associados à sua conta GitHub e lidos pela rotina de manutenção para orientar melhorias. Não envie dados de nascimento, nomes de outras pessoas, detalhes íntimos, senhas ou informações que você não queira publicar.

A aplicação funciona sem cadastro. Enviar um relato pelo GitHub é opcional e exige uma conta nessa plataforma. A leitura e eventual implementação de uma sugestão não significam endosso ao seu conteúdo nem garantem prazo de resposta.
