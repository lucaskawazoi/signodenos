# Signo de Nós

Astrologia como linguagem simbólica de reflexão e entretenimento. Sem ciência preditiva, diagnóstico ou veredito sobre uma relação.

[Conheça a aplicação](https://signodenos-prod.web.app/?utm_source=github&utm_medium=owned&utm_campaign=feedback) · [Envie feedback público](https://github.com/lucaskawazoi/signodenos/issues/new?template=feedback.yml)

Este repositório reúne informações e relatos de uso do projeto. O desenvolvimento e as publicações são assistidos por IA; conteúdo sensível ainda depende de revisão humana. Não há oferta paga, promessa de eficácia ou atendimento clínico.

## Como contribuir

Relate um problema de navegação, proponha uma melhoria ou faça uma pergunta sobre o funcionamento do site. Os relatos são públicos, associados à sua conta GitHub e lidos pela rotina de manutenção para orientar melhorias. Não envie dados de nascimento, nomes de outras pessoas, detalhes íntimos, senhas ou informações que você não queira publicar.

A aplicação funciona sem cadastro. Enviar um relato pelo GitHub é opcional e exige uma conta nessa plataforma. A leitura e eventual implementação de uma sugestão não significam endosso ao seu conteúdo nem garantem prazo de resposta.

## Operação

GitHub é usado como repositório de informações. As automações do projeto executam testes, integração, deploy e verificações no host; GitHub Actions fica desativado. O endereço próprio signodenos.com.br está em configuração. A aplicação técnica permanece acessível no endereço Firebase acima.
